# JD // Project Vault

A game-inspired portfolio that presents software projects as collectible vault assets rather than a conventional résumé page.

## Stack

- Next.js 16 / App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Lucide icons

## Highlights

- Fast boot-screen intro with skip control
- Recruiter-friendly project archive
- Project case-study routes
- Responsive game/store visual language
- Public/private source states
- No external image dependency in the initial build

## Projects currently in the vault

- Students Registration — production SaaS for academy management
- Family Finance — private finance workspace
- Plant Growth Multiplier — Fabric/Minecraft mod experiment
- NLW Habits — habit tracking learning build

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
